“十四五”是具有历史交汇性特点的五年，2021年既是中国“两个一百年”的第一个一百年节点，也是面向2035年“三步走”战略第二步的起点年。我校“十四五”时期以及更长时期的发展对加快校园建设提出了更为迫切的需求。面向未来发展，我处将立足学校发展现状，助推多校区协同发展新格局，优化有限资源使用效益，创建一流的师生服务平台，打造一流的学研生活空间，营造一流的校园文化氛围,努力成为南京大学发展的参与者和推动者，推进学校世界一流大学建设目标的早日实现。

1. <a id="_Toc29175"></a>__理清发展现状，迎接发展新机遇__

“十三五”时期，我处在学校党委领导下，紧紧围绕“统筹推进世界一流大学和一流学科建设总体方案”的建设要求，根据南京大学“十三五”发展规划发展目标，创新思路，扎实苦干，为南大双一流建设创造优质的办学条件，打造温馨的人文环境，提供最直接的民生保障，积极做好建设“第一个南大”的服务支撑工作。

1. <a id="_Toc2076"></a>__“十三五”建设成效__
2. <a id="_Toc25730"></a>__校园规划新格局__

__校园土地工作进一步推进。__“十三五”时期我处推动了仙林校区青年教职工周转房用地、仙林校区东南角约6亩土地、天文学院地块的土地勘测定界、用地审批划拨、土地证办理等工作。妥善完成了浦口校区土地划转回南京大学名下的工作。

__校区公用房规划更加优化。__根据学校对鼓楼、仙林校区的功能定位，在保障学校教学科研与事业发展需求基础上，于2016年制定了未来五年鼓楼仙林两校区用房规划方案，并依据实际情况做了进一步修订。

__主校区迁移工作逐一落实。__我处按照学校主体计划，完成两校区的学生宿舍测算与规划，及院系搬迁仙林校区进行的用房规划。一一落实了相关院系搬迁、进驻及整合工作，完成了仙林校区部分新建楼栋的交接验收工作，根据各院系实际需求，确定制作门牌号，分配物业办公用房。同时，制定完成了鼓楼校区院系搬迁后公用房调整规划方案，对鼓楼校区空置用房进行了回收、整合、修缮和用房分配管理。

1. <a id="_Toc15807"></a>__办学环境再提升__

__校园文物建筑修缮工作不断推进。__积极保护校园历史文物，充分发挥文物建筑群的历史意蕴和当代价值，传承南大文化，延续历史记忆。金陵大学旧址建筑群中的东大楼、辛壬楼及西南楼已获国家文物局立项和经费支持，目前已开启修缮工作。

__校园人文品质进一步突显。__始终贯彻“以人为本”的校园建设理念，充分利用学校现有公共空间进行微改造，为学生提供了休息交流的舒适场所，形成了疏密有方、错落有致的校园景观。仙林鼓楼两校区增加了双语户外导示标牌，拓宽了服务对象范围，增添了校园景观符号。仙林校区组团、景观及道路的命名，加深了校史文化教育意义，重塑南大文化记忆。制作学生宿舍楹联，增添校园生活活力，着墨校园文化建设。

__学生宿舍条件明显改善。__对两校区多处宿舍楼进行了整体改造和局部出新。鼓楼校区的住宿标准正从“4\-4\-3”（本科生\-硕士生\-博士生）向“4\-4\-2”转变。鼓楼校区南园8舍、陶园3舍、南园21舍改造后，由8人间改为2人间博士生宿舍和3人间硕士生宿舍，加装热水器，极大改善了鼓楼校区的住宿条件。在改造出新中着力提升宿舍家具品质，加高床体护栏，加固床体钢架，优选家具基材、拓展储物空间。仙林鼓楼两校区将部分宿舍改造为公共空间，增加自习、健身和交流讨论的场地。

__教学科研环境更具现代化。__针对仙林教学楼桌椅及黑板数量不足、设施陈旧等问题，制定公共教学课桌椅配置和采购方案。大力推动智慧教室的设计和建设，为现代化教学发展提供基础保障。完成了仙林校区教师休息室改造工程，改善教师课间休憩条件。

__生活配套服务更加优质便利__

通过公开招租，引进了罗森便利店、苹果体验店、好办一站式办公、校之友超市等一批新商铺，进一步扩充了校内经营业态，为学生与教职工生活提供了更优质的配套服务。

1. <a id="_Toc17902"></a>__民生工程稳落实__

__青年教职工住房压力得到缓解。__协调并完成了鼓楼仙林两校区周转房的基建工程，家具、家电的配置工作以及周转房启用和选房分配工作。对鼓楼校区平仓巷博士后公寓进行改造，解决了高层次引进人才来校后的过渡期住宿问题。管理上更加灵活机动，将部分预任职员及专职科研岗教师调整入住和园，为引进人才开辟绿色办理通道。同时加大对周转房、后勤集团员工宿舍管理的监管力度，及时清退不符合住宿条件的教职工。

__教师住房得到保障。__充分落实学校人才引进政策，逐年完成引进人才的和园住房点购工作，保障人才福利。2019年制定了上海路148号院士楼点房流程及销售办法，并于5月顺利完成点购工作。同年，制定了句容双创基地配套人才公寓方案，全处合心聚力，于2019年底完成全部点购工作。“十三五”时期我校积极争取人才房、限价房建设，着力解决了教职工最关心、最直接的利益问题，为教职工住房问题提供保障。

__充分解读和落实相关政策，教职工待遇不断提高。__2017年，我校根据江苏省和南京市相关文件精神，对全校教职工住房公积金、新职工住房补贴及老职工提租补贴基数、比例进行了相应上调。根据有关政策，最大程度提高教职工福利，将新职工住房补贴发放方式有原来专户存储改为随教职工工资按月发放，让我校新职工免除了原专户存储时使用上的诸多限制，使新职工住房补贴能够真正成为可自由支配收入，更切实的提高我校新职工的福利待遇。

1. <a id="_Toc5149"></a>__资产配置再优化__

<a id="_Toc10944"></a>__摸清基础数据。__2016年，我处根据财政部及教育部要求，按照单位自查、组织抽查、汇总核实、整改提高、总结上报的流程，有计划分阶段完成了各项清查任务。对我校土地及构筑物、房产出租出借、单位员工用房、全校家属宿舍已售、未售的房改住房情况进行了清查摸底；对全校车辆、家具和2007年以前建账的办公设备进行了彻底清查。对相关资料和数据进行了归档汇总，补充了资产账本。完成了两校区陈旧图纸的归档，并稳步推进鼓楼校区楼宇测绘工作，建立完整的图纸档案。我处高度重视资产台账整理工作，对房屋及构筑物数据及家具车辆资产进行了常态化梳理，及时建档建账，确保资产账目清晰，力求做到资产账账、账实相符，提高数据查阅和上报效率。

__实现信息化管理。__“十三五”时期我处信息化管理水平实现飞速发展的关键阶段，学生宿舍信息化管理系统、周转房管理系统、移动互联资产管理信息系统、家具资产管理系统、公用房管理信息系统相继开发启用。以“快速智能统计各类报表、便捷办理线上业务、辅助制定管理决策”为目的，实现了管理科学化、精细化，为建立集约、高效的综合服务保障体系提供了强有力保障。

__资产使用效率进一步提高。__提高国有资产的使用率，盘活存量，用好增量，保障重点，合理配置。提高出租资产的收益，实现资产保值增值。推进“定额配置管理,超额有偿使用”的公用房管理办法，优化公用房配置，落实公用房有偿使用管理，保障全校教师教学、科研等各项工作的正常进行；为高层次引进人才组建团队、搭建平台提供充足的发展空间。

1. <a id="_Toc19974"></a>__法治建设新成效__

__行政管理制度化建设效果显著。__我处不断深化改革，用法治理念构建管理体系，以法治方式化解现实问题，构建长效机制，实现依法治校。“十三五”时期制定了《南京大学学生宿舍管理规定》，确保我校学生宿舍管理有据可依、有理可循。出台了《南京大学房产出租出借及对外合作使用管理办法》，起草了《房产出租出借公开招租实施细则》（讨论稿），详细规定了公开招租的组织机构及职能、招租流程、合同签订、文件归档等。制定了《南京大学家具资产管理办法》。梳理了家具标牌项目采购流程、调拨流程，用“专家论证\+厂家竞拍”等方式进一步规范了家具的处置流程。出台《资产管理处招标限额以下采购实施细则》，明确了采购组织、采购流程及采购方式。起草完成《南京大学公务用车处置专项方案》、《南京大学保留车辆管理办法》，推进我校公务用车制度改革。起草了《房地产管理处合同管理实施细则》，规范了全校家具、标牌及装具等的采购需求论证以及合同审批流程；同时，积极梳理物业、租房租地等业务的合同备案流程。修订了《南京大学公用房管理办法》及实施细则，保障了我校一类、二类公用房的及时回收、科学调配；通过奖励机制和减免措施，盘活存量，助力南大“双一流”建设。

__管理体制更加灵活机动。__以问题为导向，针对重点难点，加强综合协调能力。依据行业管理准则，依托各业务实体形成专业化管理的服务保障体系。推进家属小区物业化管理，积极协调组织我校各家属小区业委会筹建、改选工作，努力推进家属小区自立自治，配合业委会协调处理家属区相关问题、矛盾，努力构建和谐校区。探索“拎包入住”的酒店管理模式，全权委托专业的酒店管理公司，为启动和园D”区4幢作为周转房公寓做好充分准备。

3. <a id="_Toc26927"></a>__中长期愿景__

1. <a id="_Toc19345"></a>__发展战略__
2. <a id="_Toc23774"></a>__以全局战略眼光谋篇布局__

站在学校发展角度，立足顶层设计，根据学校对四个校区的功能定位，对土地、用房作总体规划布局，根据学校事业的发展，保障教学科研需求，优化和完善学生生活服务设施布局，观大势、谋全局，统筹协调我校用房需求。

1. <a id="_Toc8413"></a>__将协同发展理念渗透到综合改革中__
