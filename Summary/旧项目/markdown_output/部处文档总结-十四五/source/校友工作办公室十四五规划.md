# 校友工作办公室十四五规划

__南京大学校友工作办公室十四五规划__

为贯彻南京大学第十一次党大会的会议精神，根据南京大学“十四五”规划编制的总体要求，结合校友工作的实际情况，制定本规划。

__一、发展现状与分析__

__1\. 发展现状__

“十三五”期间，在校党委、行政的领导下，在海内外各校友组织、全校各院系部门和广大校友的大力支持下，校友工作贯彻“服务校友、服务母校、服务社会”的宗旨，积极进取，开拓创新,取得了显著的成绩。

（1）在服务校友方面，自2015年以来，新成立校友组织22个，国内15个，海外7个，校友组织总数达到106个；新成立生物医药、投资研究、国际医健、智能制造与工业互联网4个行业校友组织，目前的7个行业校友组织，已成为新时代校友工作满足校友“知识分享”、“事业发展”需求的重要平台。举办各类大型活动2000余场，“海外校友子女夏令营”、“校友微捐赠”、“校园集体婚礼”、“校友口述历史”、“南大人之路报告会”、“首届校友返校嘉年华暨2019校友足球赛”等品牌活动，展现了南大人团结凝聚、健康向上的精神风貌。顺应移动互联时代需求，加强微信公众号建设，上线“南大人”校友云服务平台。连续编辑出版《南大校友通讯》20期，新增《南京大学校友工作简报》（月报），强化宣传时效性。2016年以来，承接校友返校活动超过500场、覆盖返校校友两万余人；选聘32个院系的450余名毕业生为校友年级联络员；新建南大院系校友工作微信群，覆盖30个院系57位院系校友工作人员；全面完成院系调研工作，形成了调研报告与推进举措。

（2）在服务母校方面，明确了“紧扣学校中心开展工作”的整体方向，自2015年以来，在校友捐赠方面，校友组织和校友们通过持续、稳定的捐赠支持母校发展与学生培养，徐新国际交流奖学金、赵世良讲座教授、钱东奇的“人工智能与量子物理基金”、郑钢基金等校友项目有力支持了发展工作。在招生工作方面，从2016年发展至今，目前有近30个地区的校友组织和校友成为母校招生工作的稳定力量。在学生培养方面，邀请10位杰出校友作为开学典礼、毕业典礼发言嘉宾，激励毕业生成长成才；校友们受聘“就业规划导师”、“创新创业导师”、“专业兼职导师”和通识课程讲师，为在校学生开设通识课程、双创课程和各类专题专业讲座，支持学校“三三制”人才培养。在学生就业方面，依托行业校友会，通过校友企业，以采取返校招聘、为在校学生设立专享实习岗位等多种形式助力毕业生高质量就业。2019年，首次集中组织同行业校友企业举办专场招聘会，直接助力学生就业。

（3）在服务社会方面，特别是2018年以来，针对南京市提出的推进“校友经济”发展的战略要求，结合学校、校友和地方经济发展需求，以“精准”和“聚焦”为导向，提出校友经济的“南大模式”：政府主导——提供政策、资金、物理空间等方面的支持，校友工作——发动、支持、参与，共同“找准一个行业、找准一个学科（群）、找准一个（批）平台性校友企业”，搭建校友经济的平台。在溧水区建立南京大学校友经济创新集群，在江北新区成立“江苏南创化学与生命健康研究院”，试点聚焦未来新兴产业、集聚优势学科和优质校友企业群的相互融合，在建邺区搭建“南京海外校友创新服务中心”，与鼓楼区政府签订校友经济战略合作协议，开启校地合作新篇章。

__2\. 竞争态势分析__

对照国内外高校在校友工作方面的情况，总结先进经验，总体上呈现出四大趋势：更加重视基础投入、更加重视服务体验、更加重视服务纵深、更加重视内外融合。具体分析如下：

1\.更加重视基础投入

加强母校在校友联络与服务物理空间方面的建设已经成为主流趋势。典型案例是同济大学的“校友之家”，2014年，同济大学将一栋老建筑“旭日楼”改造建成“校友之家”，作为校友返校礼遇、会面、讲座、沙龙、聚会等的活动场所，进而加强了校友与母校的科研、人才培养、国际化等方面的交流合作。目前，上海交通大学、厦门大学、东南大学等高校也已纷纷建立了自己的“校友之家”。此外，各大著名高校（北大、清华、浙大、上交大等）在人员配备、资金支持等方面的投入也高于我校。

2\.更加重视服务体验

加强校友的服务体验尤其是“面上服务”和“返校服务”，已经成为各大高校发力的主要方面。可以借鉴的有“校友卡”项目，各知名高校已纷纷施行，以清华大学校友卡为例，实现功能包括：校门门禁身份识别、校图书馆门禁身份识别、校内交通车免费等。同时，各高校也开始纷纷建立“校友线上服务平台”，通过移动互联网为校友工作赋能，包括清华、北大、上交大、浙大等高校已积极推进此项工作。

3\.更加重视服务纵深

 当前，随着社会经济发展，校友工作也面临着新形势与新变化：校友资源开始呈现出“有效集聚”的良好态势，校友需求已经从“联络联谊”的需要上升到对“事业发展”的追求，校友服务也随之从联络联谊向“知识分享”、“事业发展”等方面发展。各大高校积极探寻有效路径与方式，不断加大“三服务”的纵深。如，清华三创大赛、北京大学创新创业扶持计划、浙江大学校友创业大赛、“同济校友产业创新联盟”、武汉大学\-企业家联盟等等。

4\.更加重视内外融合

近年来，学校处于“双一流”建设的关键时期，这些新形势、新变化需要“强化母校为中心，内外融合，双元驱动，共享共进”的指导思想。目前，“校友\+院系\+在校生”内外融合的工作模式，已成为校友组织开展工作的重要趋向。这当中，最为基础的是对于校友返校活动的策划与开展，可以借鉴的如浙江大学集体婚礼、北师大京师文化节、清华大学校庆活动等等。在此基础上，校友对于母校的科研、人才培养、队伍建设和国际化方面的支持才能具备可能性。

__二、规划目标与建设思路__

__1\. 规划目标__

围绕“校友南大”建设的总体战略与要求，抓牢“120周年校庆”的时机，以“生态构建”与“平台建设”为关键点，持续完善校友联络与服务的功能体系，加强校友服务母校中心工作平台集群的建设，以“校友经济”为突破，全面构建融合服务“校友、母校、社会三位一体”的校友工作新生态。

__2\. 发展战略与建设思路__

（1）服务体验提升战略——夯实基础，创新引领，形成更加完备的校友联络与服务体系，全面提升校友的服务体验。包括：“校友之家”的建设、校友返校服务体系、地方校友组织创新发展体系、校友线上服务体系、校友年级联络体系等。

（2）品牌与文化建设战略——以“品牌”创新为发展思路，营造具有南大特色的校友文化。包括：反映校友校园生活集体记忆的“校友文化中心”的建设、校友特色品牌活动的建设等。

（3）服务学校提质战略——整合各类校友资源，构建服务学校中心工作的多方位平台。包括构建四大平台：校友经济推进平台、校友参与成果转化平台、校友参与联合科研平台、校友参与人才培养平台。

（4）队伍活力增强战略——针对校友工作队伍的现状，形成针对性的工作机制，着力做好四支队伍的建设。包括专职工作人员队伍、院系校友工作队伍、校友志愿者队伍、学生志愿者队伍。

（5）资金保障支持战略——面对校友工作资金紧缺的现状，注重引入资源对于校友工作的支持，以校友总会为平台，构建校友工作的资金保障支持体系。

__三、建设内容__

__1\. 主要任务__

（1）“校友南大”战略的生态建设

围绕“校友南大”建设的战略目标，着力推进两大板块工作：一是加强基础性工作的建设与推进，尤为关注校友联络与服务的“民心工程”，重点建设校友联络与服务所必需的物理空间，打造符合移动互联时代要求的线上服务平台，创新发展校友联络与服务的组织体系，提升以校友需求为导向的服务内涵等；二是在此基础上，加强校友与母校的密切联系和深度合作，持续发挥校友资源对于母校招生和就业工作的支持，积极探寻校友参与母校学科建设、科学研究、人才培养、队伍建设和国际交流合作的有效路径与创新机制。

（2）构建多方参与的校友工作体系

梳理整合各类资源，创新机制，努力构建“以母校为中心”全员参与的校友工作体系。贯彻学校党委、行政对于校友工作的战略领导决策，以校友工作办公室、校友总会秘书处为校友工作的内、外枢纽，形成校内以各院系、部处单位为支持的服务网络，校外以各地方、行业、专业、兴趣等校友组织为结点的校外兼职工作体系，辅以校友、学生等志愿服务网络，进而形成校友工作多方参与的合力。

（3）营造具有南大特色的校友文化

总体上强化以母校为中心的理念，突出校园的校友文化建设，真正形成校友精神家园的文化氛围；以品牌活动建设为抓手，提升校友对于母校声誉提升的贡献度；深入贯彻“内外融合”的理念，加强校友与在校生的融合，推进校友工作前置，强化在校生的校友意识，以及作为南大人的认同感、使命感和责任感。

__2\. 建设方案__

在具体建设方案的推进上，总体上按照学校的统一部署逐步推进，立足校友组织和校友群体，积极发动院系、部处的力量，共同促进校友工作的提档升级。具体方案如下：

（1）校友组织建设与创新发展（责任人：张锁庚、赵国方、唐泽威）；

（2）校友返校服务体系的完善（责任人：张锁庚、唐泽威）；

（3）院系校友工作体系的优化（责任人：张锁庚、赵国方、唐泽威）；

（4）信息化服务支撑平台的搭建（责任人：张锁庚、唐泽威）；

（5）校友品牌与文化建设（责任人：张锁庚、赵国方）；

（6）校友资源开发与运用平台的构建（责任人：张锁庚、赵国方、唐泽威）。

     时间安排上，2021年，完成各项工作的明确计划，并实施开展相关工作；2022年，围绕“120周年校庆”，重点突出返校服务、院系校友工作、信息化服务等工作任务，务求出成绩、显特色；2023\-2024年，细化、落实各项工作，力争实现规划的目标；2025年，查漏补缺，总结不足，促进规划任务与目标的全面实现。

__四、重点突破__

围绕“校友南大”战略，加强校友组织建设与发展，重点做好行业校友组织的发展工作；加强校友工作的基础性建设（物理空间、网络空间），突出强化院系校友工作和校友返校相关工作，不断提升校友服务体验；加强校友与母校的联系与密切合作，努力形成“母校关心校友，校友全面支持母校”的新局面。

1. __具体工程和项目__

1\.“校友之家”与“校友文化中心”建设工程

为贯彻“校友南大”战略，启动“校友之家”与“校友文化中心”建设。努力建成凝聚海内外校友，完善校友工作体系的综合性物理平台，促进校友文化与校园文化建设，增进校友之间、校友与母校之间的广泛合作，加强校内外融合，实现从点到面，既关注重点校友，也服务广大校友。同时，助力推进鼓楼校区整体改造提升，迎接建校120周年。

2\.“南大人”校友云服务平台建设工程

为更好地服务全球校友，通过“互联网\+”为校友服务赋能，建设校友专属网络服务平台，构建面向全球校友的联络、活动与服务体系，融合考虑“校友卡系统”、“校友关系管理系统”等校友联络与服务项目。从而扩充现有宣传平台，提升服务体验，融合校友组织工作、海外校友工作、行业校友工作、院系校友工作于一体。

3\.校友品牌与文化建设工程

着力打造一批反映校友需求、体现南大特色的品牌活动，形成以“表达忠诚、荣耀母校、彰显团结、传承精神”为主题的校友文化氛围。在现有“海外校友子女夏令营”、“校友口述历史”、“守望相助校友微捐赠”、“全球校友年会”等传统品牌活动的基础上，重点加强“校友返校嘉年华”活动的策划与举办。

4\.南大校友经济模式推进工程

以服务校友“职业发展”和“终身学习”为导向，持续加强行业校友组织建设，促使“校友\+母校\+城市”更加紧密的合作，进而实现服务校友、服务母校和服务区域经济“三位一体”的融合发展模式。具体包括“校友终身学习计划”、“南大系校友产业联盟”、“校友创新创业大赛”等项目。
