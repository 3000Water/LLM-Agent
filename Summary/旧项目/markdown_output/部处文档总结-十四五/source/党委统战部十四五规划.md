# 党委统战部十四五规划

__党委统战部“十四五”规划__

根据校“十四五”发展规划编制工作领导小组要求，制定本规划方案。

__一、发展现状与分析__

__1、“十三五”建设回顾__

自2016年7月南京大学“十三五”规划启动以来，南京大学党委统战部在学校党委和上级统战部门的领导下，把握时代方位，锚定使命任务，紧扣加强党对统一战线工作的集中统一领导这个根本，切实引导全校党外知识分子增强“四个意识”，坚定“四个自信”，做到“两个维护”，围绕中心、服务大局，进一步凝聚南京大学广大统一战线成员的智慧和力量，为学校“双一流”建设和省市区提高地区首位度、促进经济社会发展等方面做了大量工作、发挥了积极作用。

__强化思想政治引领，加强党外知识分子思想政治工作。__以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十八大、十九大以及历次全会精神，深入学习领会习近平总书记关于加强和改进统一战线工作的重要思想，认真贯彻落实中央统战工作会议、第二次全国高校统战工作会议、全省部署会议以及统战工作重要会议精神，贯彻落实《中国共产党统一战线工作条例（试行）》、《中共中央统战部、中共教育部党组关于加强新形势下高校统一战线工作的意见》以及《中共江苏省委关于贯彻<中国共产党统一战线工作条例（试行）>的实施办法》等相关文件精神。通过民主党派、统战团体日常活动“平时学”、通过民主党派统战团体负责人例会“集中学”、通过举办每年一期的统战理论研修班、青年党外知识分子理论研究班等培训班“重点学”，强化理论理解，重在统一认识，切实引导全校党外知识分子增强“四个意识”，坚定“四个自信”，做到“两个维护”。抓住重大时间节点，做深做细做实党外知识分子思想教育工作，组织庆祝中华人民共和国成立70周年暨人民政协成立70周年系列等活动、大力开展“不忘合作初心、继续携手前进”系列主题教育。理论教育与实践考察相结合，组织民主党派统战团体骨干赴井冈山、西柏坡等革命圣地实地考察学习，体会革命精神，开展传统教育。做到思想引领全覆盖、旗帜鲜明讲政治，凝聚最大共识、强化内心认同。我校党外知识分子思想政治工作获得省委统战部肯定，2020年5月，我校在全省党外知识分子统战工作推进会上作经验交流。

__强化制度思维，加强党外代表人士队伍建设__。注重在干部考察、交流和教学科研管理工作一线发现优秀党外代表人士。建立党外后备干部数据库，建设一支政治可靠、年龄结构合理、专业层次分明的党外后备干部梯队。做好四期、共19位党外干部校内“行政副职”挂职的上岗与考核工作。加强党外人士校外实践基地建设，挂牌成立了南京大学射阳高新技术研究院等实践基地，为党外代表人士的成长创造条件、搭建平台。认真做好党外人士的实职安排工作，注意选配德才兼备的党外人士担任学校各级行政、学术机构领导职务。积极对外推荐输送，举荐优秀党外人士担任各级人大代表、政协委员、政府参事、文史馆员，统战部门和组织部门协调配合，共同做好党外干部的选拔任用工作。

__强化服务理念，加强统战基层组织建设__。配合政治交接步伐，圆满完成了党派团体换届工作，加强党派团体组织建设，为党派基层组织建设注入了新的精干力量。注重“新型政党制度建设”和“双一流”建设背景下，各党派、团体基层组织建设和功能发挥。鼓励各民主党派、统战群团发挥特长、利用资源优势，围绕打赢疫情防控阻击战、后疫情时代发展、脱贫攻坚战，紧扣学校“熔炉工程”、“第一资源开发”等教学、科研、人才培养等中心工作开展形式多样的主题活动，加强品牌建设，提升各基层组织的显示度和影响力，开展“与南大同行”系列活动。形成了民革[“两岸大讲堂”](https://tzb.nju.edu.cn/86/5a/c356a296538/page.htm)、民盟“烛光·牵手·出彩”系列、民建企业家进校园系列、农工党校园义诊活动、致公党引凤工程系列、九三学社“科学和平周”系列，[校侨联、欧美同学会“留学报国系列”、“第一资源开发”系列、“新南大人”系列、“百人问卷调查”系列](https://tzb.nju.edu.cn/99/76/c356a235894/page.htm)，知联会“知联大讲堂”高端讲座等等活动品牌。围绕省市区对高校的智力、人才、科技成果转化等方面的需求，进一步凝聚南京大学广大统一战线成员的智慧和力量，切实为学校“双一流”建设和省市区提高地区首位度、促进经济社会发展等方面发挥作用，开展了“统战系统双柏行”、民革“博爱书香”系列、民盟“南京江北新区发展论坛”、校侨联、欧美同学会国情考察系列活动。推动各民主党派、统战群团共建，服务社会发展。九三南京大学委员会赴江苏师范大学开展了以“强化交流合作、助推高质量发展”为主题的校际党派交流活动。民盟南大委员会赴双柏一中、盐城中学等学校授牌成立“烛光·牵手·出彩”行动基地，开展科普讲座，服务于我校“熔炉工程”建设和地方中学教育发展。加强党派、团体参政议政能力建设，鼓励党派、团体围绕学校改革发展以及地方经济建设重大战略开展调研，提交报告。

__强化平台建设，创新海外统战工作__。加强与侨务部门和外界涉侨团体联系，拓展境内外海外统战工作。成立高校首家“南京大学为侨服务工作站”，并与省侨办联合建设南京大学华智研究中心，充分发挥平台作用，邀请侨政部门进校园做政策宣讲，为新引进人才面对面解决问题。配合中国侨联、江苏省侨联在我校成功举办海外侨领培训班（7月6\-9，中国侨联“海外侨领培训班”），来自英国、法国、意大利、肯尼亚等28个国家的60余名海外侨领在我校完成研修班学习课程。与来我校调研的江苏省侨联领导共同探讨海外人才引进、新侨产学研基地建设等工作。多次接待香港“同行万里”中学生内地交流计划、中华职业教育社台湾大学生南京研习营，让港台同胞、海外侨胞了解祖国大陆的政治制度、教育文化和发展成就，凝聚共识，进一步增强他们对中华民族的认同感。会同江南大学等高校党委统战部参与举办江苏省高校留学人员统战工作论坛暨“海创江南”海归人才产学研对接会，助力留学人员开展创新创业活动。

__强化协同运作，认真做好民族宗教工作__。在大统战格局下，我校不断完善党委领导、统战部协调、相关部门共同参与的协同运作机制。适时更新校民宗工作领导小组成员名单，定期召开小组会议，明确成员单位民宗工作联系人，健全协同工作机制。宣传部负责舆情监控和思想宣传，人事处（教师工作部）管理少数民族教师，学工部门进行民族学生和学生宗教教育管理，基层院系具体实施；海外教育学院留学生宗教管理，国际处负责外籍教师管理，保卫处查处控制，通过宗教学系开展专业的宗教研究。定期开展民族宗教工作专题讲座。与栖霞区、鼓楼区联动，共同防范校园宗教渗透。

__强化主体责任，完善大统战格局__。在学校党委的高度重视下，贯彻落实党委统战部门在“大统战”格局建设中的引导作用和主体责任，强化大统战格局。积极加强与组织、人事等相关部门的协调联系，围绕学校党委“支部建设年”的宏观部署，落实“教师党支部设立统战委员”，获得中央统战部肯定。继续推动全校统战工作重心下移，夯实基层基础，激发全域统战活力。定期召开统战工作会议暨基层统战工作培训会。完善院系级党委统战工作机制，把统战工作纳入院系级党委考核指标体系。

__强化作风建设，筑牢支部堡垒__。以深入开展“不忘初心·牢记使命”主题教育为契机，教育引导部门全体人员切实增强政治责任感和历史使命，在学习贯彻习近平新时代中国特色社会主义思想方面更有成效，在思想政治和党性作风方面更受洗礼，在全心全意服务统战对象生方面更加自觉，在担当作为方面更为坚定。利用各级统战期刊和统战网络，进一步加大统战工作在校内外的宣传力度。不断探索新媒体阵地建设与创新，“南大统战”微信公众号影响力逐步扩大。加强与省市及鼓楼、栖霞、浦口统战工作部门及兄弟高校的联系合作，多次承办全省高校统战部长培训班，交流研讨高校统战工作、互学互鉴。加强理论研究，形成了一定的理论研究成果，获得省委统战部表彰。配合学校网络信息中心开发人事信息系统，联合开发统战信息系统。

__2、国内外竞争态势分析__

当前，随着中国改革开放的不断深入，高校统战工作的发展既面临着前所未有的机遇，又有巨大的挑战。高校始终处在经济全球化、文化多元化、社会信息化的前沿阵地。在当前我国社会发展转型过程中，中西方文化的碰撞、政治制度上的差异，使新时期高校统战对象的思想观念、价值取向日益呈现多元化趋势。大量海外人才引进以及互联网、新媒体的迅速发展，使得统战工作对象呈现思想文化信仰的复杂化。加上我国正处在社会、政治、经济等领域全面深化改革的攻坚时期，各种社会矛盾凸显，高校防范风险压力越来越大。而受高校考核评价机制等的影响，高校统战工作越来越被弱化的趋势。重科研课题、经费进账数量而轻教学质量、育人效果，重课题申报、奖项评比、成果认定，而轻教育教学工作、行政管理工作、思想政治教育工作等。高校统战工作普遍比较边缘化。

__3、存在问题__

当前，伴随着学校建设“第一个南大”、推进“双一流”建设纵深发展，学校统一战线工作的使命责任、对象范围和目标任务都发生了巨大的变化，提出了新的更高要求。虽然全校统战工作过去取得良好的成绩，但仍然存在一些突出性问题。在党外代表人士队伍建设上，输送党外干部人数与级别与南大大在全省、全国的地位不够匹配，全校中层干部中党外干部比例有待提高，青年党外知识分子培养、使用方面仍有较大空间。党派、团体组织亟待加强政治把握能力、参政议政能力、组织领导能力、合作共事能力、解决自身问题能力，进一步提升助推高质量发展效能。民族宗教工作意识有待加强。院系级党委统战工作认识不足，对统战工作缺乏主动性、积极性、创新性，存在着“说起来重要，做起来次要，忙起来不要”的现象。未能正确处理在高层次人才中发展中共党员与“将一部分优秀分子留在党外”政策之间的关系，甚至认为发展党派成员等等统战工作是在“添麻烦”。南京大学统一战线工作领导小组各成员单位协同运作机制有待进一步完善。

__二、规划目标与建设思路__

__1、规划目标__

全面贯彻落实习近平新时代中国特色社会主义思想，以及习近平总书记关于加强和改进统一战线工作的重要思想。认清形势、把握大局、聚焦任务，不断提高政治站位，进一步增强做好高校统战工作的责任感和使命感。坚持问题导向，不断改进工作方法，创新举措，完善机制，强作风、补短板、抓落实、助发展、创品牌，全面提升高校统战工作成效和水平；发挥统一战线优势、广泛凝聚共识，聚力内涵式发展、着力高质量提升，助推“第一个南大”建设、区域发展以及国家战略实施。

__2、发展战略与建设思路__

强化责任意识，着力构建大统战工作格局。健全党外代表人士队伍建设制度，丰富社会主义协商民主的制度化实践，努力画出最大同心圆。加强党外知识分子思想政治工作。把巩固共同思想基础作为统战工作的核心任务，守住政治底线，坚持一致性和多样性统一。多交、善交、真交党外朋友，增强学校改革发展的凝聚力和支持力。加强党外代表人士队伍建设。注重在教学科研管理工作一线发现优秀党外代表人士。完善党外后备干部数据库。支持统战成员参与学校民主治理、服务社会。完善党外人才推荐、党外干部挂职锻炼等制度，选配德才兼备的党外人士担任学校各级行政、学术机构领导职务。持续推进“151党外代表人士培养计划”，重点培养10位左右在全国有影响、50位左右在地方有影响的党外代表人士以及100位左右年轻党外代表人士后备人选。加强统战基层组织建设。鼓励各民主党派、统战团体基层组织围绕学校改革发展及地方经济社会发展调查研究、民主协商、参政议政。完善民族宗教工作格局。探索海外统战工作新模式。完善党委统一领导、统战部牵头协调、有关方面各负其责的大统战工作格局。围绕构建大统战工作格局，鼓励支持各部门、各院系协同创新、集成创新，创造一系列具有南大特色的品牌项目，巩固和拓展南大统战工作优势，争做全省标杆、走在全国前列。

__三、建设内容__

切实加强对统一战线工作的领导，强化大统战工作格局，健全学校党委统一领导、统战部牵头协调、党政有关职能部门和基层党委共同参与的大统战格局。积极探索党外知识分子思想政治工作的新路径新方法，做好党外知识分子思想政治工作。丰富民主形式，拓展协商渠道，通过主委例会、人大代表政协委员茶话会等形式，加强民主协商。鼓励、支持各民主党派、统战团体积极围绕学校发展战略开展调研、形成报告，提出意见建议，充分发挥党外人士在学校治理能力、治理体系建设中的重要作用。打破瓶颈，加强党外干部选拔培养和教育管理，切实保证党外干部有为有位，重点培养10位在全国具有较大影响的旗帜性党外代表人士，50位担任省市级民主党派组织、统战团体主要负责人或成长为有较大影响的党外人士，100位有培养潜力的民主党派或无党派年轻骨干成员。对党外干部“苗子”早发现、早培养，在能力提升上抓系统培训、抓实践磨练，在保障机制上重齐抓共管、重跟踪问效，注重在教学科研管理工作一线发现优秀党外代表人士，做好无党派人士认定工作、党外干部校内挂职工作，拓展党外干部校外挂职，拓宽党外干部输送渠道。在校党委领导下，全面贯彻落实党的宗教工作基本方针，着力做好抵御利用宗教对高校渗透和防范校园传教工作，弘扬正能量，维护社会和谐；进一步提高站位、认清使命，发挥统战工作优势，做好留学人员统战工作。加强统战工作队伍建设，配齐院系级党委统战员，继续推动统战工作重心下移、力量下沉，做好全校基层统战工作培训班，对统战工作队伍进行全面培训。

__四、建设方案__

加强党外知识分子思想政治工作。积极探索党外知识分子思想政治工作的新路径新方法，发挥社会主义学院的教育主阵地作用，通过专题讨论、理论研修、实践考察等形式，组织党外人士认真学习习近平新时代中国特色社会主义思想和习近平总书记关于加强和改进统一战线工作的重要思想，鼓励和引导党外人士，立足本职，为学校改革发展和社会主义现代化建设贡献力量。健全学校、院系级党委班子成员与党外代表人士两级联系交友制度，加强与党外知识分子的联系、沟通，认真听取他们的意见和建议。（负责人：统战部，时间节点：2020\-2025年）

坚持校内民主协商制度。建立健全学校重大决策听取党外人士意见和建议制度，坚持党外人士列席学校有关会议制度。通过学期主委例会、人大代表政协委员座谈会等形式，定期向党外人士通报学校教学、科研及管理等工作中的重大问题，就学校改革发展的重大决定或举措，广泛听取意见建议。保证学校教职工代表大会、校务委员会等重要议事机构中党外代表的参与。充分发挥党外人士在基层单位发展中的积极作用，并形成征求意见和反馈机制。鼓励、支持各民主党派、统战团体积极围绕学校发展战略开展调研、形成报告，提出意见建议，充分发挥党外人士在学校治理能力、治理体系建设中的重要作用。（负责人：统战部，时间节点：2020\-2025年）

在校党委的领导下，与组织部门、人事部门通力协作，加强党外代表人士队伍建设。注重在教学科研管理工作一线发现优秀党外代表人士。完善党外后备干部数据库。支持统战成员参与学校民主治理、服务社会。完善党外人才推荐、党外干部挂职锻炼等制度，选配德才兼备的党外人士担任学校各级行政、学术机构领导职务。健全党外代表人士队伍建设制度。（负责人：统战部，时间节点：2020\-2025年）

加强统战基层组织建设。鼓励各民主党派、统战团体基层组织围绕学校改革发展及地方经济社会发展调查研究、民主协商、参政议政，继续不断提高政治把握能力、参政议政能力、组织领导能力、合作共事能力、解决自身问题能力。（负责人：统战部，时间节点：2020\-2025年）

在校党委的领导下，与保卫处、学工处、研工部、海外教育学院、继教院积极合作，防范风险、守住底线，完善民族宗教工作格局。（负责人：统战部，时间节点：2020\-2025年）

在校党委的领导下，与国际处、发展委、校友会、人力资源处、双创办等部门通力合作，探索海外统战工作新模式。（负责人：统战部，时间节点：2020\-2025年）

在校党委的领导下，完善党委统一领导、统战部牵头协调、有关方面各负其责的大统战工作格局。（负责人：统战部，时间节点：2020\-2025年）

__五、重点突破__

在校党委的领导下，持续推进“151党外代表人士培养计划”，重点培养10位左右在全国有影响、50位左右在地方有影响的党外代表人士以及100位左右年轻党外代表人士后备人选。

丰富形式，注重实效，加强思想引领。发挥社会主义学院的教育主阵地作用，通过专题讨论、理论研修、实践考察等形式，组织党外人士认真学习习近平新时代中国特色社会主义思想和习近平总书记关于加强和改进统一战线工作的重要思想，鼓励和引导党外人士，立足本职，为学校改革发展和社会主义现代化建设贡献力量。利用好统战之家、政协委员之家平台，充分发挥脱贫攻坚、党外知识分子创新创业基地、校地共建工作作用，在实践中凝聚共识。

以治理能力提升为重点，加强民主党派、统战团体基层组织建设。支持民主党派、统战团体加强思想建设、组织建设和领导班子建设；支持民主党派基层组织和无党派人士围绕学校教学、科研及人才培养等中心任务开展相关工作并积极发挥作用；支持民主党派和无党派人士围绕经济社会发展等重大问题开展考察、调研及社会服务活动；支持他们依法履行参政议政、民主监督以及参加中国共产党领导的政治协商职能；以服务中心参政议政为路径，增强能力建设。
