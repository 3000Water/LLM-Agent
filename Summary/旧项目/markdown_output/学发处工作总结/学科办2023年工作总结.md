# 学科办2023年工作总结

__学科建设与发展规划办公室2023年度工作总结__

2023年度，学科建设与发展规划办公室在学校党委行政的领导下，深入学习宣传贯彻党的二十大精神和习近平总书记重要回信精神，积极开展学习贯彻习近平新时代中国特色社会主义思想主题教育，坚决落实“奋进行动”，谋划实施一流学科培优行动，优化学科布局，深入推进“双一流”建设，开展省优势学科四期启动工作，推进苏州校区学科建设，全面服务学术委员会工作。办公室全员团结一致，齐心协力，群策群力，扎实推进各项工作，取得了显著成效。

__一、积极开展主题教育，以高质量党建提供坚强保证__

学科办党支部把贯彻落实习近平总书记关于教育的重要论述和重要指示批示作为第一优先级事项，根据学校党委关于开展学习贯彻习近平新时代中国特色社会主义思想主题教育工作部署，积极筹划组织支部活动，通过中层干部专题党课、红色沂蒙行等主题党日活动、各类专题组织生活、支部共建、专题调研等多种形式开展主题教育，持续深学细悟。

深化“讲政治、守纪律、负责任、有效率”机关创建，引导办公室全员始终做党中央战略意图的忠诚实践者，围绕国家、学校的决策部署形成务实、有效的实施方案，健全相应流程，确保主题教育落地生根、见到实效，以高质量党建为业务工作提供坚强的政治保证。

__二、坚决落实“奋进行动”，谋划实施一流学科培优行动__

积极主动对接国家“十四五”规划及科技、哲社相关规划，协同“卓越研究计划”“十百千工程”，形成《南京大学一流学科培优行动方案（讨论稿）》。教育部领导两次实地考察了计算机科学与技术、物理学、地质学、信息资源管理等四个学科并给予充分肯定，为我校争取更多学科入选“一流学科培优行动”计划打下坚实基础。

以扬长项、强弱项为重点，进一步加大基础学科投入，持续推进基础学科高质量建设。与科技处、社科处、人力资源处等相关职能部处开展深入合作，推动加强科研平台和师资队伍建设，重点打造优势方向。

__三、优化学科布局，探索新兴交叉学科推进机制__

结合国务院学位委员会相关政策文件，持续推进《南京大学博士硕士学位授权自主审核方案》修订工作，拟根据教育部有关文件精神适时出台，统筹推进学术学位和专业学位两类授权点高质量发展。完成2023年学位授权自主审核工作（新增教育学博士一级学科，出版、材料与化工博士专业学位类别，应用伦理硕士专业学位类别，剧场与影像学、行星物质与演化、环境标准与装备博士目录外二级学科），完成2023年学位授权点专项核验工作，持续推进2020\-2025年学位授权点周期性合格评估工作。基于我校学位授权点增列和调整结果，编制并发布《南京大学研究生教育学科专业目录（2023年）》。

针对“AI for Science”、数学学科、生命科学与医学学科、学科交叉与交叉学科发展、现有一级学科下设二级学科建设等内容开展专题调研，进行校内学科交叉机构建设情况摸底，梳理交叉学科建设成效与经验，有序推进新兴交叉学科建设和交叉平台建设。完成教育部学科交叉中心试点建设及江苏高校学科交叉中心的申报。

__四、改进学科评价工具与结果运用，持续推进“双一流”建设__

根据教育部有关要求，组织完成第二轮“双一流”建设中期总结自评工作，于2023年7月19日召开南京大学第二轮“双一流”建设中期自评会。评议专家一致认为：南京大学实现了第二轮“双一流”建设中期的预期建设目标，符合度好，达成度高，高质量完成了中期建设任务。针对中期总结工作中的2022年度“双一流”建设动态监测任务，学科办通过制定科学合理的工作方案以及与有关院系和职能部处保持密切联系，高效完成了填报任务，梳理了当年度学科建设情况，并以动态监测为基础系统整理建设成效数据，加强对“双一流”建设成效评估的分析工作。

紧密围绕“双一流”建设目标，持续优化学科亮点工程。召开多场学科亮点工程实施评审会，根据上一年度亮点工程建设情况，综合考虑学科的整体性、成长性和可持续性，完成对以学科亮点工程为主的学科评价体系和预算目标体系的梳理与优化，研究实施分层分类的学科精准支持机制，进一步建立健全学科高峰建设推进机制。

推进南京大学学位授权点信息填报与评审系统建设，完成学位授权点与用户信息管理、学位授权点数据填报与审核、专家评审等功能的开发，结合新建院系、自主审核、专项核验等实际业务场景开展功能测试，完成了项目验收。

__五、积极对接地方需求，开展优势学科四期启动工作__

深入谋划、提早准备，在省优势学科四期启动之前，学科办详细梳理了我校各学科建设情况，结合优势学科三期建设和学科评估等建设成效，积极对接省教育厅，为学校争取更多支持。我校优势学科建设数量由三期的19个大幅增长至四期的27个。经详细摸排学校已有建设成果和未来建设成果可能性，学科办对“优势学科标志性成果指标体系”提出的多项建议被教育厅采纳入任务书编制文件中。目前优势学科四期立项工作已全面启动。在进行各学科任务书编制工作的同时，学科办结合三期验收成绩和第五轮学科评估情况，将四期经费与“双一流”建设经费统一测算和分配，体现学校统筹。

高质量完成《南京大学“双一流”建设高校服务国家重大战略需求和江苏经济社会发展任务书》，助推我校更好地融入国家和区域经济建设与社会发展大局。根据省教育厅相关工作安排，完成“十四五”江苏省重点学科中期检查工作，确定我校推荐评优名单。

__六、深入论证科学规划，推进苏州校区学科建设工作__

根据学校“十四五”规划和苏州校区发展规划，探索新兴交叉学科建设新路径，增强服务长三角一体化国家战略和地方社会经济发展重大需求，组织完成苏州校区新设学院的论证工作。基于充分调研和全方位论证，完成了苏州校区能源与资源学院、前沿科学学院的设置，推动苏州校区建设进入新的阶段。

起草《苏州校区学科建设规划（2024\-2028年）》，以进一步明晰苏州校区学科建设定位，强化学科顶层设计，提升学科内涵，加快苏州校区学科建设步伐，加强与南京校区相关学科的优势互补与高效联动。

__七、用好国际评估，客观务实反映学科建设成绩__

密切关注世界大学排名的相关资讯和动态变化，积极参加THE世界大学排名大师班、爱思唯尔、科睿唯安专题研讨会等活动，扎实做好与相关机构的沟通联系和数据报送工作。顺利完成2023年度QS和THE世界大学/学科排名的数据采集、统计报送及核验。

持续深化国际大学和学科排行榜的常态化跟踪统计和分析，及时凝练我校亮点与特色，提高数据使用效能，为学科建设各项工作提供重要支撑。紧密围绕学科建设中心任务，系统梳理THE、QS、软科、USNEWS等主流世界大学排名指标体系，吃透排名指标内涵，分析2023年THE、QS新指标引入的导向和思路，全面总结我校排名表现，提出合理性发展建议。

__八、发挥学术委员会作用,推进新时代学风建设__

组织召开2023年度校学术委员会全体会议。本科生院、科学技术处、学科建设与发展规划办公室有关负责同志分别向校学术委员会汇报了学校迎接本科教育教学审核评估工作情况、“南京大学AI&AI for Science”发展规划、第二轮“双一流”建设中期自评工作情况等。委员结合汇报内容，对学校相关工作提出了建设性意见建议。

持续加强学风建设，完成学校《有关学风建设的部分文件与案例汇编》首版的编纂，经校学术委员会审议和有关职能部处意见征求后送相关部门使用。2023年度，迄今共受理涉嫌学术不端事件14件，其中10件已完成调查，均未认定构成学术不端行为。根据教育部要求，反馈了针对《高等学校学术不端行为调查处理的实施细则（征求意见稿）》的修改意见。

__九、发挥专家组织作用，提升“双一流”建设支撑条件__

完成学科评议组/专业学位教指委委员推荐工作，推荐谭铁牛院士等四名新增学科专业相应的学科评议组或专业学位教指委成员人选。完成宗教学教育指导委员会委员申报、我校江苏省医学类研究生教育指导委员会委员调整等工作。

积极承担长三角联盟秘书处工作，开展长三角联盟高层论坛、长三角研究型大学联盟理事会会议暨校地合作平台建设论坛、异地科研机构建设论坛等活动的沟通联络，促进长三角高校在更高层次、更高水平、更高质量上开展战略合作，共同推动长三角高等教育一体化发展。
