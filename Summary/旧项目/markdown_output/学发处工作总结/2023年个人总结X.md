# 2023年个人总结X

__2023年工作总结__

__1\. 推进南京大学“奋进行动”，实施优化学科布局行动方案__

__（1）完成2023年学位授权自主审核工作。__根据《南京大学学位授权审核实施办法》（南字发〔2018〕155号）,开展我校2023年度学位授权自主审核工作，经院系申报、学科办初审、校学位评定委员会审议、专家论证、公示、校学位评定委员会表决、校长办公会及校党委常委会审议等程序，完成新增教育学博士一级学科，出版、材料与化工博士专业学位类别，应用伦理硕士专业学位类别，剧场与影像学、行星物质与演化、环境标准与装备博士目录外二级学科的自主审核工作，并按照教育部相关工作要求完成材料上报。

__（2）有序推进新兴交叉学科建设和交叉平台建设。__进行校内学科交叉机构建设情况摸底，梳理交叉学科建设成效与经验，完成教育部学科交叉中心试点建设及江苏高校学科交叉中心的申报工作。

__（3）加强二级学科/专业领域建设。__完成对现有一级学科下设二级学科建设情况的调研并形成报告；完成了对通信工程、集成电路工程、光电信息工程、材料工程、环境工程、制药工程等6个工程硕士专业领域的转设备案，完成了在临床医学博士专业学位类别下儿科学、老年医学、精神病与精神卫生学、皮肤病与性病学、急诊医学、全科医学、儿外科学、骨科学、眼科学、耳鼻咽喉科学、麻醉学、临床病理、放射肿瘤学等13个专业领域的新增设置，强化内涵建设；根据国务院学位委员会发布的《研究生教育学科专业目录（2022年）》相关学位授权点对应调整结果和代码及名称变更结果，完成我校自主设置的信息资源管理、数字媒体公共设计艺术等2个目录外二级学科的撤销工作、以及艺术文化学目录外二级交叉学科的挂靠一级学科调整工作；基于我校学位授权点增列和调整结果，编制并发布了《南京大学研究生教育学科专业目录（2023年）》。

__2\. 推进学位授权点周期性合格评估工作__

根据2020\-2025年学位授权点周期性合格评估工作安排，持续推进本年度合格评估工作，主要包括：（1）组织61个参评学位授权点填写《学位授权点建设年度报告》，协同研究生院编制《研究生教育发展质量年度报告》，并将以上材料在学科办官方网站公开；（2）开展学位授权点自我评估工作，组织各参评学位授权点填写《南京大学学位授权点自我评估简况表》，组织开展针对所有参评学位授权点的形式审查和专家评审会，并形成诊断性专家意见。

__3\. 完成2023年学位授权点专项核验工作__

根据教育部2023年学位授权点专项核验工作安排，组织我校新闻传播学博士一级学科、临床医学博士专业学位类别、以及应用心理、电子信息、材料与化工、资源与环境、生物与医药、工程管理等6个硕士专业学位类别等共计8个学位授权点开展相关工作，完成学位授权点基本状态信息的在线填报、以及核验意见的通知与反馈工作。

__4\. 开展第五轮学科评估及专业学位水平评估后续工作__

第五轮学科评估及专业学位水平评估结果于2022年底通过机要方式下发至参评单位，按照教育部相关保密工作要求，结合疫情防控工作需要，经请示学校领导同意，第一时间以线上形式将评估结果逐一向参评学科进行了传达；编制《南京大学第五轮学科评估及专业学位水平评估结果分析报告与工作总结》，完成第五轮学科评估及全国专业学位水平评估分析服务采购工作。

__5\. 完成新建院系论证工作__

根据苏州校区管委会申请，就在苏州校区建设能源与资源学院的相关事项，在征求各部处意见的基础上，组织召开专家论证会并形成专家组意见，经校领导审议通过，完成苏州校区能源与资源学院的设置；完成苏州校区前沿科学学院的设置。

__6\. 推进学位授权点信息系统建设工作__

推进建设南京大学学位授权点信息填报与评审系统，完成学位授权点与用户信息管理、学位授权点数据填报与审核、专家评审等功能的开发，结合新建院系、自主审核、专项核验等实际业务场景开展了功能测试，并完成了项目验收。

__7\. 完成“十四五”江苏省重点学科中期检查工作__

根据省教育厅相关工作安排，组织我校光学工程等10个“十四五”江苏省重点学科立项学科开展并完成《中期检查报告》的在线填报工作，经学科办形式审查，确定我校推荐评优名单，并按省教育厅要求完成相关纸质材料的报送工作。

__8\. 完成江苏高校优势学科建设工程四期项目立项学科任务书编制工作__

根据省教育厅相关工作安排，组织我校应用经济学等27个江苏高校优势学科建设工程四期项目立项学科开展并完成任务书的在线填报、专家论证等工作。

__9\. 配合有关单位完成学科建设相关工作__

学科办完成的其他学科建设相关工作主要包括：

（1）完成学科评议组/专业学位教指委委员推荐工作。根据国务院学位委员会办公室通知，推荐谭铁牛、王恒、任保平、任雪娟为智能科学与技术、应用伦理、数字经济、气象等4个《研究生教育学科专业目录（2022年）》中新增学科专业相应的学科评议组或专业学位教指委成员人选。

（2）完成我校江苏省医学类研究生教育指导委员会委员调整工作。

（3）完成宗教学教育指导委员会委员申报工作。

（4）完成部分学位授权点的申请基本条件意见反馈工作。根据全国工程专业学位研究生教育指导委员会的相关要求，经征求相关院系意见，完成对《电子信息等8个专业学位类别博士硕士学位授权点申请基本条件（征求意见稿）》的意见反馈。

（5）完成理论经济学、政治经济学专项调研工作。根据《关于开展理论经济学学科建设和人才培养情况专项调研的通知》《关于组织填报<政治经济学学科建设情况统计表>的通知》，组织有关学科相关调研及统计材料并反馈至国务院学位委员会办公室。

（6）完成国际中文教育学科建设情况回复工作。根据南京大学人大代表、政协委员关于加强国际中文教育学科建设的建议，对我校国际中文教育学科建设情况开展调研，并对相关内容予以回复。
