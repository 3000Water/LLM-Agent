# 2023年个人总结L

__2023年工作总结__

__一、协助领导组织第二轮“双一流”建设中期自评工作__

根据教育部有关文件要求，今年学校组织开展了第二轮“双一流”建设中期总结自评工作。主要工作有：一是组织会议。包括“双一流”建设自评工作动员大会，一流建设学科自评工作专家评审会、学校自评工作专家评审会等。二是协调沟通。梳理了21个部处单位中期自评工作撰写任务清单，汇总整理反馈了15位专家共72份一流学科专家评审意见，发送相关邮件达上百封，专门申请了“双一流中期自评工作”微信群，自评期间一直密切保持与各个部处单位一流学科的交流咨询。三是撰写材料。起草了《南京大学第二轮“双一流”建设中期自评工作方案》，一流学科中期自评工作撰写提纲，部处单位中期自评工作撰写提纲，学校自评工作专家评审会上的主持词欢迎词总结讲话和专家论证意见等各种材料，参与撰写完成了《南京大学“双一流”建设中期自评报告》等，并上报教育部。

__二、协助领导加快推进学科高峰建设__

根据学校党委工作部署和落实“奋进行动”的要求，协助领导全力推进学科高质量发展。主要工作有：一是优化“学科亮点工程”，健全学科高峰建设推进机制。根据去年“学科亮点工程”建设情况，综合考虑学科的整体性、成长性和可持续性，全面梳理优化以“学科亮点工程”为主的学科评价体系和预算目标设置体系。以学科发展目标为牵引，统筹规划、精准支持，加强经费与学科建设之间的关联，做到经费管理、绩效考核、学科评估三者高度结合，充分发挥“双一流”建设的导向和激励功能。二是启动“一流学科培优行动”，加快推进一流学科领域取得新突破。根据领导有关要求，撰写“一流学科培优行动”计划，起草一流学科培优行动建议提纲，组织相关学科撰写《一流学科培优行动任务书》，其中教育部领导两次实地考察了计算机科学与技术、物理学、地质学、信息资源管理等四个学科并给予了充分肯定，为争取我校有更多学科入选“一流学科培优行动”计划打下了坚实基础。三是积极谋划，科学布局，全面推进基础学科高质量建设。与科技处、社科处、人力资源处等相关职能部处深入合作，以实现数学、生命科学、哲学、历史学等基础学科的跨越式发展，并逐渐形成一批具有引领示范和辐射带动作用的学科高峰。

__三、撰写重要文稿__

主要工作有：1\.起草撰写《南京大学“双一流”建设高校服务国家重大战略需求和江苏经济社会发展任务书》；2\.起草撰写《苏州校区学科建设规划（2024\-2028年）》；3\.起草撰写报送中办材料《当前我国基础学科建设布局情况、存在的问题和不足及对策建议》；4\.起草撰写报送教育部材料《南京大学关于编制教育强国建设规划纲要的有关建议》；5\.起草撰写报送教育厅材料《南京大学“双一流”建设学科2018年以来重大科研成果》，全省遴选了12个一流建设学科的成果上报省委省政府和教育部，我校入选了5个学科；6\.参与撰写《全面支撑中国式现代化江苏新实践行动方案》；7\.学校领导在“C9高校‘双一流’建设研讨会”的发言稿；等等。

__四、支部工作__

作为支部组织委员和机关党委党建工作联络员，主要工作包括协助书记组织召开支部支委会议、组织生活会议、党课学习；做好会议记录和相关工作提醒；收缴党费；做好新进党员的组织关系交接；完成智慧党建管理服务平台的填报；撰写有关材料并及时上报给机关党委；并在支委届满和领导更换之际，及时完成支委换届选举等等。由于工作调整，9月以后不再继续支委相关工作。

__五、办公室工作和领导临时交办的任务__

一是办公室的印章管理，并做好每次印章使用的登记工作。二是完成了学科办《2022年南京大学年鉴》的相关撰写工作。三是协助领导做好中南财经大学、兰州大学、国家教育行政学院、深圳大学、陆军工程大学等兄弟院校的接待工作。四是领导临时交办的撰写任务，包括教育部基础学科调研材料、教育部学科设置相关建议材料、本科迎评学科办提交的相关材料、修订学科办“奋进行动”相关材料、学科办年度亮点工作、学科办“奋进行动”工作进展，等等。
