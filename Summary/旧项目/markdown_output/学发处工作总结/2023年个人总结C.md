# 2023年个人总结C

__工作总结__

__一、积极投身主题教育工作__

根据校机关党委关于开展学习贯彻习近平新时代中国特色社会主义思想主题教育有关工作部署，在学科办支部统一安排下，做好宣传委员工作。积极组织筹划支部活动，通过专题党课（中层干部讲党课）、主题党日活动（红色沂蒙行等）、专题组织生活（“全面贯彻二十大精神 加快建设‘第一个南大’”大讨论集体研讨等）、党员自学（购买《党政机关公文标准与格式应用指南》、习思想系列丛书等）、集体学习（习近平外交思想的科学体系及其对中国外交的指导意义\-杨洁勉讲座等）、支部共建（政府管理学院行政管理教师支部研讨等）、专题调研等多种形式，开展主题教育，及时撰写各类活动宣传材料。设计学科办党支部主题教育方案、读书班方案、调研方案，及时进行各项问题清单、调研课题清单统计，以高质量党建为业务工作提供坚强的政治保证。

__二、高质量完成“双一流”各项工作__

1\.完成2023年“双一流”和优势学科预算：组织召开三场学科亮点工程实施评审会。邀请专家，组织26个院系根据去年“学科亮点工程”建设情况、经费执行情况以及今年建设计划进行现场汇报，及时反馈专家评审意见，一对一联系并指导各院系及时在一体化预算系统中填写详细预算，圆满完成2023年“学科亮点工程”院系申报和部门审核等相关工作，完成学科经费分配。以学科建设为基础，以学科发展目标为牵引，加强经费与学科建设之间的关联。充分调研，统筹规划、精准支持，做到经费管理、绩效考核、学科评估三者高度结合，根据部处和学院等建设单位申请和建设实际需求，进行“双一流”建设经费动态调整，国家“双一流”引导资金53940万元，年度执行率100%，序时执行进度完全达到财政部要求。

2\.开展2023年国家“双一流”绩效监控、绩效监测和动态调整工作：根据教育部要求，对2023年预算批复各项目开展绩效监控，主要包括绩效目标完成情况、预算资金执行情况等，与各部处沟通确认任务完成情况，按时按要求提交项目支出绩效执行监控材料；分别为14个院系提供2022年度“双一流”建设监测学科建设经费参考数据。完成“双一流”领导小组人员调整文件发布工作，根据“双一流”领导小组会议指示及各部门执行情况，动态调整经费安排，做好平时经费拨款、预算审核和督促执行工作。

3\.做好2024年“双一流”相关工作：

2024年国家“双一流”引导专项经费预算申报工作：与本科生院、研究生院、人力资源处、科技处、社科处、国际合作与交流处、双创办、财务处等职能部处保持紧密联系，同时科学填报学科预算，严格按照文件要求，从拔尖创新人才培养、师资队伍建设、提升自主创新能力和社会服务能力、文化传承创新和国际合作交流五大方向，结合设备资产申报，填报一上预算，主要包括：项目支出申报依据、实施方案的撰写，支出计划、各项子活动测算依据和绩效目标申报表的整合填写，圆满完成2024年国家“双一流”一上预算提交工作。

2024年“双一流”全面预算工作：由于国家财政预算一体化政策变化，预算项目控制更加精细化、刚性化，需要进一步提前谋划、精准预算。为更加合理、严格地编制预算，结合财务预算一体化管理，与财务处联合召开2023年度财务工作会议，会上给全校各预算部门结合工作实际进行详细讲解，总结了预算编制的注意事项，提醒各院系各单位尽早谋划，准确完成学科预算编制与执行工作。设计了“部处预算申报书”，首次组织各部处提前填写预算，填写过程中保持密切沟通，及时反馈修改，目前部处预算内容正在完善中。设计了适应预算新形势的“学科亮点工程计划任务书”，突出重要事项填写。组织召开四场“学科亮点工程暨学科预算评审会”，31个学院进行现场汇报，回顾总结2023年学科亮点和预算执行情况，提出2024年绩效指标和预算执行计划。会后请部处进行正式评级，后续将根据评审情况，反馈部处和专家意见，促进学科预算编制更加详尽和精准。

4\.调研工作：配合预算新要求，紧密跟踪各部处、院系执行进度，对执行内容进行分析总结；对全校各学科兼职教授、专职科研和编外人员等劳务费情况以及2023全年支出情况进行统计分析；对学校准长聘人员、青年人才等多项人才计划经费支持情况进行详细摸排和调研，对2016年以来专项经费进行统计整理，为动态调整和精准支持提供有力数据支撑，促进“双一流”建设经费依规编制、统筹编制、科学编制，进一步保障“双一流”建设资金高效、精准投入。

__三、高水平开展优势学科四期启动工作。__

1\.准备工作：梳理我校各学科建设情况，结合我校优势学科三期建设和学科评估等建设成效，积极对接上级主管部门，向教育厅提出了如“参考学科评估结果直接认定”、“分类建设”等建设性意见，为我校争取到更多支持，《省教育厅关于公布江苏高校优势学科建设工程四期项目立项学科名单的通知》（苏教研函【2023】11号）公布，我校优势学科建设数量由三期19个大幅增长至四期27个。在任务书编制文件发布前，教育厅就“标志性成果指标体系”向我校征求意见。将工作做实做细，从三期验收申优指标、征询每个建设学科建议、征询各部处建议三方面入手，对各项指标我校已有建设成果和未来建设成果可能性进行了详细摸排，逐项指标形成具体意见反馈。结果表明，教育厅采纳了我校多项建议，为我校四期建设优秀成果展示提供更好支持。

2\.正式启动：仔细研读《省教育厅关于做好江苏高校优势学科建设工程四期项目立项学科任务书编制工作的通知》，吃透文件精神，明确建设基本思路，厘清各项工作程序和内容，组织召开优势学科四期启动动员会暨任务书编制工作布置会，详细阐述四期启动各项工作内容，全面启动江苏省优势学科四期项目立项工作。目前各学科进行线上任务书填写，后续将按照工作安排进行材料审核和报送。在任务书编制工作进行的同时，结合优势学科三期验收成绩和第五轮学科评估情况，体现学校统筹，详细测算优势学科建设经费，提供多种经费分配方案供领导决策，与“双一流”建设经费统一测算和分配，优势学科经费目前已与院系沟通完毕。

__四、开展长三角联盟秘书处工作__

担任长三角研究性大学联盟秘书处南京大学联络人，负责联盟各类活动联系、材料整理、提供等工作。开展了长三角联盟高层论坛、长三角研究型大学联盟理事会会议暨校地合作平台建设论坛、异地科研机构建设论坛等活动的沟通、联络以及材料准备工作。撰写各类有关长三角联盟调研、汇报材料。

__五、担任办公室人事秘书、OA秘书、组织员、内控联络员，做好办公室各类工作。__

1\.做好人事秘书工作，完成补贴发放、人员职称职级评聘等相关工作；

2\.做好组织员工作，完成管理服务考核各项工作；

3\.做好OA秘书工作，处理各类办公文件流转、文件通知，完成各项文件OA发布工作；

4\.做好内控联络员工作，配合学校内控小组及治理能力提升，完成相关材料报送及领导谈话工作；

5\.做好财务联络员工作：完成2023年财经纪律重点问题专项自查自纠相关工作，完成专项资金年初预算、年终决算、收入申报工作，配合财务处完成引导专项设备费调研和调整工作；

6\.做好办公室行政管理工作：组织召开第二轮“双一流”中期自评会议，认真完成教育部、爱思维尔公司、深圳大学、陆军工程大学等来访会务、接待等工作；

7\.根据领导安排，进行临时文稿撰写及PPT制作，完成各类巡视整改报告材料整理反馈。完成《南京大学“双一流”建设领导小组议事规则》、学科办办事指南修订工作。
