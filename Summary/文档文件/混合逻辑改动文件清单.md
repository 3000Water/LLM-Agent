# 混合逻辑改动文件清单

## 📊 核心逻辑

```
对于【无子章节】的大章节（发展环境、指导方针、组织与保障）
  → 提取：按大章节 key 分类
  → 聚合：直接拼接
  → 撰写：一次性生成

对于【有子章节】的大章节（发展基础、建设任务）
  → 提取：按子章节 key 分类（更细粒度）
  → 聚合：按子章节先聚合，再组合
  → 撰写：逐子章节生成，再拼接
```
